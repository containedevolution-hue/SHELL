# SHELL's Core

SHELL's Core is the operating environment's central computer and filesystem entry point — a seed icon on the desktop that opens into a connection trunk, gauge layer, and a canopy of category surfaces (Apps, Memory Box, Photos, Task Manager, and more). Core projects stores, apps, connections, and system activity without becoming a second authority over any of it.

**Built:**
- A desktop seed icon (no crack/root/sprout), kept separate from the fixed Home control
- Boundary rule: the seed's appearance does not enable the separate SEED capture feature
- Memory Box: one entry per assistant model, isolated memory slots, SHELL custody, owner vs. assistant content stays provenance-tracked
- An accessibility/recovery contract: keyboard/screen-reader/reduced-motion equivalents, rebuild from canonical paths, distinct broken-link/permission/stale-index/backup-gap states

**Not built yet:**
- The full Core interior layout (Box/trunk/canopy visual composition)
- Trunk connection-conduit visualization (green/red/yellow per connection)
- Canopy globes for each category surface
- Customizable gauge placement and presets
- A list-and-details precision mode
